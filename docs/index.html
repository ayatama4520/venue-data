VENUETOKYO

東京の音楽イベントを
地図でひと目に。

「今夜ふと音楽を聞きたくなったけど、どこでイベントがあるかわからない」VENUE TOKYOは、そんな東京のナイトライフを楽しむ人の悩みを解決する新しい地図アプリです。(もちろんDAYイベントも対象です)

App Storeでダウンロード → 無料 / iOS
Map

光るピンが、
今夜の集合場所。

会場のピンは、イベントがある日だけライムグリーンに発光。地図を眺めるだけで、今夜どのエリアが賑うのか直感的に分かります。ジャンルや会場名での絞り込みもワンタップで。

Detail

詳細画面で、
演者と値段をチェック。

会場のピンをタップすると、その日以降のイベント情報が表示されます。開場・開演時間、料金、出演者、エトセトラ。気になるイベントは友達にそのままシェア。当日だけでなく、先の予定も立てられます。

Save

ハートをつけて、
逃さない。

行きたいイベントはハートひとつでお気に入りリストに。あとから一覧で見返せるので「いつどこに行くんだっけ?」と迷うこともなくなります。
